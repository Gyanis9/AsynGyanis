# 文档导航

[返回项目首页](../README.md)

AsynGyanis 的使用文档按开发、部署和验证场景组织。首次使用先完成构建，再按需要选择网络或数据库专题；准备部署时同时阅读运行手册与配置说明。

| 文档 | 主要内容 |
| --- | --- |
| [入门与构建](入门与构建.md) | 平台与工具要求、Conan 依赖版本、预设、安装与包消费、ABI 边界 |
| [架构设计](架构设计.md) | 模块依赖、事件循环、调度归属、协程帧与运行时生命周期 |
| [网络编程](网络编程.md) | TCP/UDP、HTTP/1.1/2/3、WebSocket、出站客户端、流式收发与认证 |
| [数据库访问](数据库访问.md) | 驱动、ORM、类型映射、连接池、事务、异步执行与重试 |
| [部署与运维](部署与运维.md) | ReferenceServer、worker、服务通知、停机与换代、TLS 和 ACME |
| [配置与可观测性](配置与可观测性.md) | 配置加载与热重载、资源限额、日志、指标、追踪和故障定位 |

| [性能测试](性能测试.md) | 微基准、本地进程外压测、基线比较、测量边界与构建选项 |

## 按任务阅读

- **第一次运行**：[入门与构建](入门与构建.md) → [部署与运维](部署与运维.md)。
- **编写 HTTP 服务**：[架构设计](架构设计.md) → [网络编程](网络编程.md) → [配置与可观测性](配置与可观测性.md)。
- **接入数据库**：[数据库访问](数据库访问.md) → [测试与验证](测试与验证.md)。
- **准备上线或排障**：[部署与运维](部署与运维.md) → [配置与可观测性](配置与可观测性.md)。
- **评估改动**：[测试与验证](测试与验证.md) → [性能测试](性能测试.md)。
